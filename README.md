# Keyboard
Building a custom keyboard for KEEB



## Hardware

| Component | Quantity | Notes |
|---|---:|---|
| Mechanical keyboard switches | 78 | Main 75% keyboard |
| Macro-pad switches | 12 | 3×4 macro pad |
| Key-switch diodes | 90 | 1 diode per switch |
| Rotary encoders | 3 | 2× rotation inputs each |
| Encoder push switches | 1 | Push function on 1 encoder |
| R503-5V fingerprint sensor | 1 | Capacitive, UART, 200 fingerprint capacity |
| I/O expander | 1 | Used to reduce Pico GPIO requirements |
| Raspberry Pi Pico | 1 | Main microcontroller |
| Trackpad module | 1 | Built into the keyboard PCB |
| OLED/display | 1 | Optional |
| Keycaps | 90 | 78 main keys + 12 macro keys |
| PCB | 1 | Custom keyboard PCB |
